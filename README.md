# 🚀 C++ 星际编程学院

面向 **小学 4 年级 ~ 高中 2 年级**、理科思维与动手能力较强的学生的 C++ 学习网站。
纯前端实现（HTML/CSS/JS），**离线可用、零依赖、零外部 API**，进度保存在浏览器 localStorage。

## 快速开始

方式一（推荐）：本地服务器
    node server.js
然后浏览器访问 http://localhost:8765

方式二：直接用浏览器打开 index.html（双击即可，全部功能离线可用）

## 核心设计

### 费曼学习法闭环（每章四步）
1. **学一学**：概念卡（讲解 + 可运行示例 + 要点清单），点「我懂了」+5 XP
2. **讲一讲**：小老师模式——用自己的话讲解概念，系统按关键 idea 组智能反馈，讲清楚 +15 XP
3. **练一练**：3 道动手编程题，内置 C++ 解释器真实运行 + 多测试点评测
4. **闯一闯**：章末趣味编程闯关（剧情化题目），通过后解锁下一章 +50 XP

### 14 章循序渐进课程
| 章 | 主题 | 章 | 主题 |
|---|---|---|---|
| 1 | 你好，C++（cout/程序结构） | 8 | 字符串魔法 |
| 2 | 变量宝盒（类型/赋值/交换） | 9 | 嵌套循环与图案 |
| 3 | 输入与运算（cin/整数除法陷阱） | 10 | 递归秘境 |
| 4 | 条件判断（if/逻辑运算） | 11 | 排序与查找（冒泡/二分） |
| 5 | 循环魔法（for/while/累加器） | 12 | 结构体 struct |
| 6 | 数组（遍历/打擂台/越界） | 13 | 类与对象（封装/构造） |
| 7 | 函数工厂（参数/返回值/复用） | 14 | 引用与 vector（STL 入门） |
| 15 | 指针罗盘（地址/解引用/指针行走） | 16 | STL 军火库（sort/reverse/binary_search）+ 终极闯关 |

共 48 张概念卡、16 个费曼讲解任务、48 道练习、16 个闯关，**209 个测试点全部通过自动化验证**。

### 伴学 AI 小机器人
- 开局 4 选 1：比特猫 / 电路龙 / 像素兔 / 齿轮熊（SVG 动画，各有性格）
- 完成练习/闯关时庆祝跳舞 + 彩带
- **每日督学**：连续打卡天数、今日 3 任务目标、回归鼓励
- **错误提醒**：失败 3 次主动提示看提示/参考答案；失败 2 次自动进错题本；挂机 2.5 分钟温柔提醒
- 点击机器人随机赠送学习方法贴士

### 游戏化激励（实时动画）
- 经验值：概念 +5 / 讲解 +15 / 练习 +20 / 闯关 +50，一次通过加成、看答案减半
- 等级与称号：编程新手 → 代码学徒 → … → 星际毕业生 → C++ 传奇大师（升级光芒动画）
- 16 枚徽章：初次点火、费曼小老师、五连绝世、调试勇士、错题克星、七日恒星、星际毕业生…（解锁吐司 + 扫光动画）
- XP 飘字、经验条流光、彩带庆祝、轻量音效（可静音）

### 直达闯关
- 每张章节卡片（含未解锁章节）都有「⚡ 直达闯关」按钮，可直接挑战章末考验
- 章节页内闯关不再强制要求先完成练习（建议先练更稳）
- 闯关通过即解锁下一章，练习可以之后补做

### 回溯学习（记忆曲线复习）
- 顶栏 🔁 / 首页「回溯学习」/ 章节页「🔁 回溯」打开回溯中心
- 机器人按艾宾浩斯曲线（通关 3 天后）生成复习建议；看过参考答案的题、错题本也会进入建议
- 每章提供 📖 概念回读 / ✏️ 重练 / 🎮 重闯 三个入口，回溯时间自动记录

### GitHub 分享
- 顶栏 📤 打开分享面板：GitHub Pages 在线链接、仓库链接、本地克隆命令，一键复制
- 在线版：https://goldfish-x.github.io/cpp-star-academy/
- 仓库：https://github.com/goldfish-x/cpp-star-academy
- 每位学习者的进度保存在自己浏览器 localStorage，互不影响

### 代码编辑器
- 语法高亮、自动缩进、Tab 缩进、Ctrl+Enter 运行、代码自动保存
- 运行（自定义输入）与提交评测（逐测试点对比期望输出，失败给出差异）
- 三级提示、失败 3 次解锁参考答案（费曼式引导：看懂→讲一遍→独立写）
- 中文友好报错（带行号）：死循环保护、数组越界、私有成员访问、除零等

## 内置 C++ 解释器（js/interpreter.js）
教学子集：cout/cin/endl/getline、int/double/bool/char/string、一维/二维数组、
vector（push_back/size/范围for）、if/else、for/while/do-while、break/continue、
函数/递归/引用参数/重载、struct/class/构造函数/方法/public/private、
指针（& 取地址 / * 解引用 / 指针算术 / nullptr）、STL 算法（sort/reverse/binary_search、vector 迭代器）、
常用内置函数（abs/sqrt/pow/max/min/swap/to_string/stoi/rand…）。
50 万步死循环保护、1200 层递归保护、6 万字符输出保护。
